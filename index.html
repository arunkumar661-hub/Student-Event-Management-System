ℹ️ About Student Event-Management System

The Student Event-Management System is an integrated web platform designed to streamline student registration, track campus/inter-college event participation, and archive prize achievements.

It connects front-end HTML5/CSS3/Vanilla JS views with a robust Java Collections, JDBC, and MySQL database layer for permanent data storage.

💻 Technology Stack

  • HTML5 & CSS3: Responsive academic design system
  • Vanilla JavaScript: Client-side dynamic state & validations
  • Java SE: OOP, Collections (ArrayList), DAO Architecture
  • JDBC: MySQL database connection & CRUD operations
  • MySQL Database: Relational data tables with foreign keys
